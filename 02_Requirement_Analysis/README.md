# Phase 2 – Requirement Analysis

## Project Objective
To improve data accuracy and consistency in ServiceNow Incident records.

## Functional Requirements
1. Make Assignment Group mandatory for High Impact incidents.
2. Make Urgency read-only for High Impact incidents.
3. Automatically set Urgency to High.
4. Prevent saving when Assigned To is empty for High Impact incidents.
5. Prevent State changes through list editing.
